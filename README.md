# CA Clover 🍀

Japan Community Activity Dashboard for Pokémon GO Community Ambassadors.

This public repository contains the public-side application source.
Its deployed Supabase/Edge Functions backend and Campfire ingestion
implementation must be maintained in a **private repository**.

- Never commit live credentials, SQL migration sources, internal Edge
  Function code, or Campfire auth-research into the public tree.
- The GitHub Pages production site is deployed from `pages/docs` and
  is unchanged by this **draft** cleanup of `main`.
- Old public Git history can still reveal old code. This change alone
  does not make historical sources confidential.

**Do not merge until the private backend repository contains all
previous source, CI, migration history, and restore instructions.**
