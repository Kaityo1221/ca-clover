# オリジナルデジタル名刺・フォントバンク（隔離準備版）

## 内容
- `font-bank.json` は日本語の筆文字フォント8種類のメタデータ台帳です。
- **フォント本体（.ttf / .otf / .woff 等）は未格納**。著作権やライセンス表示を確認するため、先に出典・用途・条件だけを管理します。
- 本ブランチは本番公開・公開デプロイ対象外です。会長から明示的なGOが出るまで本番反映しません。

## 運用ルール
1. フォント本体を取り込む場合は公式配布元から取得し、原本のライセンス文書を保存してください。
2. 各ファイルに SHA-256・取得日・出典URL・ライセンス・再配布/埋め込み可否を記録してください。
3. Google FontsのYujiシリーズはSIL Open Font License 1.1。バンドル時はライセンス同梱等の条件を遵守してください。
4. 武蔵システム配布の5書体は公式ページで無料・商用利用可能と案内されていますが、Webフォント埋め込み時の配布条件は導入前に個別確認します。
5. 名刺の試験用文言は「みんな集まれ」、裏面テンプレート「勢・墨アート」。フォントの文字欠けと視認性を320/390/430pxの画面で確認します。
6. フォントはユーザーが選択します。名刺の表裏にCloverのサービス名・ロゴを強制表示しません。
7. 実フォントファイルをDB（PostgreSQL）へ直接格納せず、適切なオブジェクトストレージに配置し、DBはメタデータ・パス・権限のみ保持する想定です。
