## フォント保存先の方針
1. DBは書体名・作者・出典URL・ライセンス・ハッシュ・ファイルパス・公開状態等の**メタデータ専用**とする。PostgreSQLにフォント本体を保存しない。
2. Yujiシリーズ3書体はGoogle FontsのCSS配信を使い、読み込み失敗時は明示的にフォールバックする。SIL Open Font License 1.1の原文：`https://github.com/google/fonts/blob/main/ofl/yujiboku/OFL.txt`
3. 他の5書体は、公式サイト（`https://opentype.jp/freemouhitufont.htm`）から配布ファイルを取得し、同梱文書を確認したあと、隔離オブジェクトストレージの `digital-business-card/fonts/<font-id>/<sha256>.woff2` 等に格納する想定。**現時点では未格納**。
4. Web配信のCORS/CSP、キャッシュ、ライセンス、再配布、文字欠け、日本語グリフを確認するまで本番に組み込まない。
5. 5書体を未導入のまま他のフォントに見せかけない。プレビューでも「導入待ち」と明示し選択不可とする。

## 名刺の設計方針
- 表：CA本人の写真・地域・コミュニティ名・右側の本人メダル・既存の一言メッセージ
- 裏：本人が選択した背景・自由入力したキャッチコピー・必要に応じた旗・プロフィールQR
- 表裏に CA CLOVER のサービス名やロゴを強制表示しない
- 参考キャッチコピー：「みんな集まれ」
- 裏面デザイン：「勢・墨アート」。左右スワイプとタップで紙をめくる動作
- 写真・本人メダル・QR・一言メッセージはプレビュー内では**ダミー**
